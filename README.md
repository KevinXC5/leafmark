# Leafmark · 叶笺

面向 macOS / Windows 的轻量本地 Markdown 编辑器，支持原位编辑、阅读模式、多标签和本地文件夹导航。

界面使用 TypeScript 与 CodeMirror 6，本地文件与系统能力由 Go 提供，MyGo 负责原生窗口和前后端通信。Bun 用于开发阶段的依赖管理、命令执行和前端测试，Vite 提供前端热更新与资源构建。技术分工与运行流程见[架构与开发](docs/架构与开发.md)。

## 功能

- 文档管理：多标签、本地文件打开、保存、另存为、独立撤销历史、自动保存与草稿恢复。
- 文件导航：文件夹树、名称筛选、近期文件、新建和重命名。
- 编辑：原位 Markdown 编辑、源码模式、查找替换、表格编辑、链接与图片插入。
- 阅读与输出：阅读模式、代码高亮、脚注、公式、提示块、上下标、Mermaid、HTML / Markdown 导出与系统打印 PDF。
- 个性化：字体、字号、行高、阅读宽度、浅色 / 深色 / 系统主题、专注模式、打字机模式和快捷键自定义。

## 使用说明

### 文档与文件夹

新建或打开 Markdown 后，文档显示为独立标签。每个标签保留自己的内容、选区和撤销历史；重复打开同一文件会切换到已有标签。标签上的圆点表示有未保存修改，关闭时可以保存、放弃修改或取消关闭。最后一个标签关闭后显示欢迎页。

保存失败或取消保存时，窗口与草稿继续保留。文件被其他程序修改后，应用会暂停自动保存，可通过文件菜单检查变化并从磁盘重新加载。有未保存修改时，重新加载需确认放弃修改。另存为不能覆盖其他已打开标签的文件。

侧栏“文档”页用于打开工作区文件夹、浏览 Markdown、筛选名称、刷新、新建文档或文件夹、重命名，以及在 Finder / 文件资源管理器中定位。重命名不能覆盖已有文件；重命名已打开文件或包含已打开文件的目录前，需先关闭相关标签。近期文件最多保留 30 条，可在设置或导航中清空。

### 编辑与格式

原位编辑模式在正文中显示 Markdown 效果，当前活动行可显示语法标记；源码模式显示完整 Markdown。支持 H1–H6 标题、加粗、斜体、删除线、行内代码、引用、有序 / 无序 / 任务列表、代码块、链接、图片、表格和分隔线。

选中文字后可使用浮动格式工具栏，完整格式操作位于格式菜单。点击任务复选框可切换完成状态。大纲根据标题生成，点击条目可跳转，并标记光标所在章节。查找替换支持区分大小写、全词、正则表达式、前后匹配、单个替换和全部替换。

顶层闭合代码块提供语言标识、语法高亮、复制和编辑按钮。顶层 `$$` 公式与单行 `$…$` 公式支持原位显示，编辑对应位置时可回到源码。源码模式支持 Markdown / GFM，以及 JavaScript、TypeScript、JSON、Python、Go、Rust、Shell、SQL、HTML、CSS 代码高亮。

链接弹窗支持插入、修改和移除链接。图片可通过 URL 或本地文件插入：已保存文档的图片复制到 `./assets/<文档名>/`，重名时追加编号；未保存文档使用图片 Data URI。本地相对图片可在编辑与阅读模式中显示。

表格以实际表格形式显示，通过按钮或双击进入编辑器，可编辑单元格、增删或移动行列、调整对齐。一次保存表格对应一次撤销操作。引用或列表中的表格保留源码显示。

### 阅读与导出

阅读模式支持 CommonMark / GFM、代码高亮、脚注、行内与块级公式、提示块、文本高亮、下标、上标、隐藏文档头部元数据（frontmatter）、`::: details 标题` 折叠内容和 Mermaid 图形。原始 HTML 作为文本显示；无法渲染的 Mermaid 图形保留源码并显示中文提示。

HTML 导出内嵌样式、本地图片和 Mermaid SVG，可离线打开；远程图片保留原 URL。Markdown 导出生成副本，当前编辑文件保持不变。PDF 通过系统打印界面选择“存储为 PDF”或 Windows PDF 打印机生成。

### 设置、自动保存与恢复

字体可选择 Newsreader、系统衬线、系统无衬线和等宽字体，字号范围为 12–28 px，行高范围为 1.3–2.2。阅读区提供窄、舒适和宽三种选项，主题支持浅色、深色和跟随系统。设置还包括实时渲染、当前语法、专注模式和打字机模式。

开启自动保存后，已有文件路径的当前文档停止输入两秒后保存；未命名文档需先另存为。其他文件操作完成后继续安排自动保存。

本机草稿恢复存储未保存内容，意外重启后可恢复为新标签并另存为。每份草稿上限为 1 MiB，总量上限为 5 MiB。超限或存储失败时显示提示并保留旧快照；选择“稍后”时保留待恢复草稿。

### 默认快捷键

快捷键可在设置中录制、修改和恢复默认，冲突的快捷键无法保存。`Mod` 在 macOS 上为 ⌘，在 Windows 上为 Ctrl。

| 动作 | 默认快捷键 |
| --- | --- |
| 新建 | Mod+N |
| 打开 | Mod+O |
| 保存 | Mod+S |
| 另存为 | Mod+Shift+S |
| 关闭标签 | Mod+W |
| 查找替换 | Mod+F |
| 加粗 / 斜体 | Mod+B / Mod+I |
| 链接 | Mod+K |
| 阅读切换 | Mod+Shift+R |
| 设置 | Mod+, |

### 使用限制

工作区扫描跳过隐藏文件、`node_modules` 和符号链接，最多扫描 10,000 个条目与 64 层目录。文档长度超过 1,000,000 个 UTF-16 代码单元时，代码块和表格以源码显示；部分字符（如 emoji）占用两个代码单元。

外部修改检测不能完全避免多个程序同时写入造成的覆盖。Windows 已完成交叉编译与安装包生成，尚未实机验证。输入法、系统打印与原生文件选择框等人工验收范围见[架构与开发](docs/架构与开发.md#验证覆盖与验收边界)。

## 本地开发

开发环境需要 Go 1.27.1+ 和 Bun 1.4.2+。运行已打包的应用无需安装这些开发工具。

安装依赖并启动桌面开发应用：

```bash
bun install --frozen-lockfile
bun run dev
```

仅启动网页开发服务：

```bash
bun run dev:web
```

桌面开发支持前端热更新。真实本地文件和系统能力通过桌面应用验证。

## 验证与构建

日常检查包括 TypeScript 类型检查、前端测试和 Go 测试：

```bash
bun run check
```

原生自动化验证：

```bash
bun run verify:native
```

原生验证在 macOS WKWebView 中测试编辑、磁盘保存、多标签和自动保存等场景，完成后自动退出。平台覆盖与人工验收范围见[架构与开发](docs/架构与开发.md#验证覆盖与验收边界)。

构建当前系统与架构的应用，跳过 DMG 和公证：

```bash
bun run build:local
```

产物位于 `build/<平台>-<架构>/`。

发布检查与多平台构建：

```bash
bun run check:release
bun run build -- -platform darwin/universal,windows/amd64,windows/arm64
```

## 下载与自动更新

正式版本从 [GitHub Releases](https://github.com/KevinXC5/leafmark/releases) 下载。macOS 的 Apple 芯片使用 darwin-arm64 DMG，Intel 芯片使用 darwin-amd64 DMG；Windows 根据架构选择 amd64 或 arm64 的 Setup 安装程序。

正式版启动十秒后检查更新，持续运行时每二十四小时检查一次。发现新版本后可选择安装或稍后处理；也可在“设置 → 通用 → 软件更新”查看当前版本、手动检查和安装。更新包经过 Ed25519 签名校验，安装后下次启动生效。请保存文档后正常关闭应用，再重新打开。

开发构建和安装目录不可写时禁用自动更新。当前安装包未配置 Apple Developer ID 公证与 Windows Authenticode 签名，首次运行时操作系统可能显示来源验证提示。

## 项目结构

```text
main.go                 Go 启动入口
internal/desktop/       MyGo 服务、原生对话框、窗口生命周期与原生验证
internal/documents/     文档、标签、保存基线、编码与外部修改检测
internal/workspace/     工作区目录树、路径授权与近期文件
internal/assets/        图片验证、读取与文档附件导入
src/main.ts             前端入口
src/app/                应用装配、主界面模板与全局样式
src/editor/             编辑操作、文档统计与源码高亮
src/editor/live/        Markdown、代码块、公式与表格的原位渲染
src/editor/dialogs/     链接、图片与表格编辑对话框
src/markdown/           阅读与导出渲染、Mermaid、扩展语法
src/documents/          文档会话、草稿同步与恢复快照
src/file-browser/       工作区文件树与近期文档
src/settings/           应用偏好与快捷键设置
src/platform/mygo.ts    MyGo 自动生成的前后端接口
src/types/              第三方模块的类型声明
scripts/                构建、预览与浏览器验证脚本
tests/                  按源码功能目录组织的前端测试与基准测试
verification/           原生验证输入与运行输出
```

前端通过生成接口调用桌面服务，桌面服务调用 Go 业务包。职责边界、接口生成与构建流程见[架构与开发](docs/架构与开发.md)。开发与验证约定见 [AGENTS.md](AGENTS.md)。

## 离线预览

生成包含脚本、样式、字体和 Mermaid 的单文件界面预览：

```bash
bun run preview:export
```

产物为根目录的 `Leafmark-preview.html`，可直接打开。预览文件和 `verification/` 中的运行输出不纳入版本库。
