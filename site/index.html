# 轻量 · 本地 · Markdown 编辑器

落笔， 即成文。

##01原位编辑

语法，只在你落笔的
那一行出现。

原位编辑把 Markdown 直接渲染在正文里。光标所在的行会露出语法标记，方便修改；离开之后，又收回成排好版的文字。

想看全貌时，一键切到源码模式，完整的 Markdown 一字不差。

→点一点右边的任意一行试试

山中来信.md +
# 山中来信
雨停在午后。把窗推开，纸上还留着一点潮气。
> 写作，是把一闪而过的念头慢慢说清楚。

##02功能

写作需要的，都在手边。

山中来信.md 叶脉笔记.md 读书摘抄.md +

多标签，各记各的

每个标签保留自己的内容、选区和撤销历史。未保存的修改用圆点提示，意外退出后，草稿可以恢复为新标签。

笔记 山中来信.md 叶脉笔记.md 草稿 筛选名称…

以文件夹为工作区

打开一个文件夹，浏览其中的 Markdown，按名称筛选、新建、重命名，并在访达或资源管理器中定位。近期文件随手可回。

层级作用
主脉输送与支撑
侧脉向两侧分流

表格，就是表格

以真实表格显示，双击进入编辑器：改单元格、增删与移动行列、调整对齐。一次保存对应一次撤销。

Qn = Q · rn 主脉侧脉细脉

公式与图形

行内与块级公式原位显示，代码块按语言高亮；Mermaid 在阅读模式里绘成图形。

叶(脉|柄).*Aaab 替换为…3 / 12

查找与替换

区分大小写、全词匹配、正则表达式，逐个替换或一次全部替换。

专注与打字机

专注模式让其余段落退到远处，打字机模式把正在写的一行留在视线中央。

.html.md.pdf

带得走的成品

导出的 HTML 内嵌样式、本地图片与 Mermaid 图形，离线也能打开；PDF 交给系统打印。

Aa文Aa{}

合手的版面

四种字体，字号 12–28，行高 1.3–2.2，三档阅读宽度；浅色、深色，或跟随系统。

##03阅读模式

换一种目光，再读一遍。

写完之后切到阅读模式，全文按 CommonMark 与 GFM 渲染：提示块、公式、图形与表格各归其位。点一下后面的窗口，把它拿到前面来。

同一篇笔记，两种主题
  • CommonMark / GFM
  • 代码高亮
  • 脚注
  • 行内与块级公式
  • 提示块
  • 文本高亮
  • 上标与下标
  • 折叠内容
  • Mermaid 图形
  • frontmatter 隐藏

##04本地优先

你的文字，
留在你的磁盘。

没有账号，没有专有格式。每一篇文档都是文件夹里的一份 Markdown，换一个编辑器照样打得开。

自动保存
开启后，停止输入两秒即写回磁盘。
草稿恢复
意外重启后，未保存的内容可以恢复为新标签。
外部修改检测
文件被其他程序改动时暂停自动保存，由你决定是否重新加载。
签名更新
更新包经 Ed25519 签名校验，安装后下次启动生效。

##05快捷键

手不离键盘。

常用动作都有默认快捷键，也可以在设置里录制、修改和恢复默认；冲突的组合不会被保存。

  • 新建ModN
  • 打开ModO
  • 保存ModS
  • 另存为ModShiftS
  • 关闭标签ModW
  • 查找替换ModF
  • 加粗ModB
  • 斜体ModI
  • 链接ModK
  • 阅读切换ModShiftR
