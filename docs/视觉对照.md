# 视觉对照记录

对照对象：`Leafmark.pen` 中的主编辑窗口（浅色 `bi8Au`、深色 `u9bxh7`、Windows `Q7qald`）、交互细节（`k5goS`）、查找与插入细节（`HvCnG`）、设置（`d0ahEC`）。参数均取自原型节点，而不是目测近似。

## 字体

| 用途 | 字体 | 来源 |
| --- | --- | --- |
| 界面文字 | Inter | 侧栏、标签、状态栏、弹窗控件 |
| 正文与标题 | Newsreader | 编辑区、阅读模式、设置预览 |
| 代码与公式 | Geist Mono | 代码块、行内代码、快捷键显示 |

原型的界面文字全部标注 `Inter`，正文标注 `Newsreader`，代码标注 `Geist Mono`。此前代码使用 IBM Plex Mono，中文正文回退到系统宋体，与原型观感不同；现已按原型字体族加载 400/500/600 及斜体，中文仍回退系统衬线字体。

正文默认 18px、行高 1.6、阅读宽度 856px；标题按比例 34/23/19px（深色主题为 38/26/22px）。设置中调整字号或宽度时会整体按比例生效。

## 主窗口

| 元素 | 原型参数 | 当前实现 |
| --- | --- | --- |
| 侧栏尺寸 | 248 × 884，圆角 18，内边距 8/16/20/16 | 一致 |
| 侧栏材质 | 底色 `#D8CCB899` + 纵向透光渐变 + 侧缘反光 + 1px 渐变描边 + 背景模糊 30 + 内外阴影 | 分层渐变与遮罩描边实现 |
| 侧栏切换 | 高 34，底色 `#E8E0D5`，选中项 `#FAF6EE` | 一致 |
| 大纲条目 | 高 39，间距 6，文字 12px Inter，级别标记 9px 等宽 | 一致 |
| 大纲选中 | 浅色 `#F1DAC5` / `#965B3A`，深色 `#443833` / `#E1C1AC` | 一致 |
| 标题栏 | 高 40，仅标签与新建按钮 | 标签、`+`、右侧 `⋯` |
| 标签 | 高 30，图标 12px，文字 12px，选中 `#F0E6DB` / `#79513C` | 一致 |
| 状态栏 | 高 34，文字 11px，色 `#857C72`，上边框 `#E8E3DA` | 一致 |
| 代码块 | 底色 `#F3F0E9`，边框 `#E8E1D7`，圆角 5，内边距 16/18 | 一致 |

原型标题栏只有文档标签和新建按钮，没有常驻菜单行。功能入口改为：标签条中的 `+`、右上角 `⋯`（保存、主题、文件操作、格式、查找、阅读、设置）以及快捷键。保存与主题按钮保留在文档结构中以便自动化调用，但不占用视觉布局。

## 弹窗

| 弹窗 | 原型参数 | 当前实现 |
| --- | --- | --- |
| 链接浮层 | 宽 372，圆角 10，背景模糊 18，标题 13px 600，地址输入 36px | 一致，含移除链接与折叠的文本/标题 |
| 图片弹窗 | 宽 513，标题栏 36px，来源切换、预览、替代文本、附件说明 | 一致 |
| 表格弹窗 | 宽 513，单元格 40px，选中 `#EED0B7`，分组标签 10px | 一致，含行列增删、移动与对齐按钮组 |
| 设置 | 1000 × 800，左栏 208，分类项 42px，面板白底圆角 10 | 一致，含字体、字号、行高、宽度、主题、快捷键与通用 |

弹窗统一使用 Inter 12/13px 界面字号，表头 11px，正文单元格 Newsreader 13px，避免此前的 26px 衬线大标题。

## 查找替换

原型为两行紧凑布局，高 92，底色 `#E8E3DA`，输入框 32px、底色 `#FFFCF7`，替换按钮使用强调色。当前实现按同尺寸与配色排列为：首行查找输入、上下一个、全部选中、区分大小写、正则、全词匹配与关闭；次行替换输入、替换与全部替换。

## 已知差异

- 原型使用英文界面文案，当前为中文；结构、尺寸与配色保持一致。
- Windows 版原型在标题栏左侧有文件与格式菜单按钮，当前统一使用右上角 `⋯`。
- 设置页分类标题在原型中为英文大写，当前为中文分组名。
- 中文正文回退到系统衬线字体，字形与原型中的拉丁文示例不同。
