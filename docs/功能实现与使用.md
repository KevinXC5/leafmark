# Leafmark 功能与使用

实现日期：2026-10-02。技术路线：MyGo 0.1.22、Go、TypeScript、CodeMirror 6。设计源文件为 `Leafmark.pen`。

## 文档与本地文件

- 新建、打开、保存和另存为 Markdown。
- 多标签切换，每个标签保留独立内容、选区与撤销历史；重复打开同一文件切到原标签。
- 标签上的圆点表示未保存。关闭脏标签时可保存、放弃或取消；最后一个标签关闭后显示欢迎页。
- 原生窗口关闭前锁定正文、同步草稿，再检查所有标签。保存失败或取消保存会保留窗口和草稿。
- UTF-8 文本，支持中文与 emoji；保留读取文件的 BOM、CRLF 和原权限。
- 保存检查外部修改摘要；另存为拒绝覆盖其他已打开标签的文件。文件写入使用同目录临时文件和原子替换。
- 窗口重新取得焦点时检查磁盘变化，也可在文件菜单主动检查。发生变化时暂停自动保存，支持从磁盘重新加载；脏文档重新加载需要明确放弃修改。
- 页面刷新保留进程内全部标签和准确保存基线；恢复草稿使用安全 Markdown 文件名。
- 自动保存：设置中开启后，已有磁盘路径的当前文档停止输入两秒后保存；未命名文档仍需先另存为。忙碌操作结束后继续调度。
- 本机恢复草稿：仅保存未保存内容，意外重启后可恢复为新标签，随后另存为。每份上限 1 MiB，总量 5 MiB；超限或存储失败会提示，保留旧快照。选择“稍后”的旧草稿继续保留。

## 文件夹导航

侧栏“文档”页可打开工作区文件夹、递归浏览 Markdown、筛选名称、刷新、新建文档或文件夹、重命名和定位到 Finder / 文件资源管理器。

扫描跳过隐藏文件、`node_modules` 和符号链接，最多 10,000 个条目、64 层目录。重命名禁止覆盖；已打开文件及包含已打开文件的目录需先关闭标签。近期文件最多 30 条，可在设置或导航中清空。近期列表只授权其中已记录的文件路径。

## 书写与格式

- 原位编辑与完整源码模式切换，当前活动行可显示 Markdown 标记。
- H1–H6、加粗、斜体、删除线、行内代码、引用、有序／无序／任务列表、代码块、链接、图片、表格和分隔线。
- 选中文字时出现浮动格式工具栏；格式菜单提供完整操作。
- 任务复选框点击直接修改 Markdown 的完成标记。
- 顶层闭合代码块提供语言、语法高亮、复制和编辑按钮；顶层 `$$` 公式与单行 `$…$` 公式在原位显示，活动位置可回到源码。
- 源码模式支持 Markdown/GFM 与 JavaScript、TypeScript、JSON、Python、Go、Rust、Shell、SQL、HTML、CSS 代码语言高亮。
- 大纲跟随标题生成，点击跳转，并标记光标所在章节。
- 查找替换：区分大小写、全词、正则、前后匹配、单个替换和全部替换。
- 链接弹窗支持插入、修改和移除链接，拒绝危险协议。
- 图片弹窗支持 URL 与本地文件。已保存文档的图片复制到 `./assets/<文档名>/`，重名追加编号；未保存文档使用图片 data URI。本地相对图片可在原位和阅读模式显示。
- 原位表格提供真实表格显示，按钮或双击进入编辑器。可编辑单元格、增删行列、移动行列和调整对齐，一次保存可一次撤销。引用／列表容器内表格保留源码。

## 阅读与导出

阅读模式支持 CommonMark / GFM、代码高亮、脚注、行内／块公式、提示块、highlight、sub/sup、frontmatter 隐藏、`::: details 标题` 容器和 Mermaid 图形。

HTML 导出内嵌样式、已解析的本地图片和 Mermaid SVG，可直接离线打开；远程图片保留原 URL。Markdown 导出为副本，不切换编辑中的文件。PDF 通过系统打印界面选择“存储为 PDF”或对应 Windows PDF 打印机。

原始 HTML 默认作为文本处理，渲染结果经 DOMPurify 净化。Mermaid 使用严格模式，禁用交互链接、外部图片及自定义配置，并限制代码规模。错误图形保留源码和中文提示。

## 设置与快捷键

设置支持 Newsreader、系统衬线、系统无衬线和等宽字体；字号 12–28 px、行高 1.3–2.2、窄／舒适／宽阅读区；浅色／深色／系统主题；实时渲染、当前语法、自动保存、专注模式和打字机模式。

快捷键可在设置中录制与修改，冲突会被拒绝，支持恢复默认。`Mod` 在 macOS 为 ⌘，Windows 为 Ctrl。

| 动作 | 默认快捷键 |
| --- | --- |
| 新建 | Mod+N |
| 打开 | Mod+O |
| 保存 | Mod+S |
| 另存为 | Mod+Shift+S |
| 关闭标签 | Mod+W |
| 查找替换 | Mod+F |
| 加粗 / 斜体 | Mod+B / Mod+I |
| 链接 | Mod+K |
| 阅读切换 | Mod+Shift+R |
| 设置 | Mod+, |

## 验证边界

自动测试覆盖前端格式、渲染安全、表格、设置、快捷键、恢复、异步文档生命周期和文件导航，以及 Go 文件操作、路径授权、图片、编码与并发。macOS WKWebView 原生测试覆盖中文内容、撤销重做、真实磁盘保存与重新读取、多标签草稿、关闭取消、两秒自动保存、工作区与相对图片、外部变化检测和重新加载。前端 175 项测试通过；真实浏览器端到端脚本 16 项检查通过。

代码块与表格预览在超过 1,000,000 个 UTF-16 字符的文档中回退源码，避免复杂块解析拖慢编辑。字数按不可变文本缓存增量统计；大纲来自语法树，包含 ATX／Setext 标题。16 MiB 首次字数统计本机约 160 ms，缓存后的局部编辑统计约 0.02 ms；这些数据不包含全部编辑器和草稿桥接成本。

原生后台 WebView 的浮动工具栏未取得焦点，工具栏显示和点击由浏览器真实交互验证。Windows 完成交叉编译与安装包生成，尚未实机运行。拼音候选词、组合输入、Windows 输入法、系统打印和完整原生文件选择框交互仍需人工验收。

外部修改检测是保存前的最佳努力检查；其他程序在检查完成到替换之间修改文件，无法作为跨进程原子事务保证。AI 功能不包含在此版本中。
